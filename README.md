## 🌟 Key Features

### 1. 🎬 4-Stage AI Video Evaluation Rubric (100 Total Marks)
- **Video 1: Problem Statement Understanding (Max: 15 marks)**
  - Problem clarity, target audience understanding, and real-world relevance.
- **Video 2: Pitch Deck Presentation (Max: 20 marks)**
  - Idea innovation, solution clarity, feasibility, and pitch delivery.
- **Video 3: 50% Prototype Demonstration (Max: 25 marks)**
  - Implementation progress, working features, AI integration, and technical feasibility.
- **Video 4: Final Project Demonstration (Max: 40 marks)**
  - End-to-end functionality, technical quality, UI/UX, and real-world impact.

### 2. 🤖 Gemini AI Video Analysis & Judge Overrides
- Autonomous video transcript analysis and rubric evaluation via Google Gemini 2.5 Flash / Pro.
- Human judge score overrides, custom notes, and per-video manual grading.
- Automatic tie-breaker engine (Final Demo score > Prototype score > Manual Judge Review).

### 3. 🥇 Automatic Winner Announcement & Ceremony
- Dynamic podium crowning: **Grand Champion (Winner)**, **Runner-Up**, and **Second Runner-Up**.
- Interactive celebratory confetti ceremony and winner result ratification.
- Leaderboard CSV export and formatted social media announcements.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/VACOMMUNITY/judgetool.git

# Navigate to project directory
cd judgetool

# Install dependencies
npm install

# Start development server
npm run dev

# Or build and preview production
npm run build
npm run preview -- --port 4173
```
